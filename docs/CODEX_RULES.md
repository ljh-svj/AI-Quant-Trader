# Codex Developer Rules

你是本项目高级 Python 工程师。

## 开发原则
1. 修改代码前先理解项目结构。
2. 保持模块化设计。
3. 每次重要功能完成后提交 Git。
4. 新增功能必须包含必要注释。
5. 关键模块需要测试。
6. 所有交易策略必须经过回测和风险分析。

## 开发路线
Phase 1: 数据获取与行情管理
Phase 2: 技术指标分析
Phase 3: 策略系统
Phase 4: 回测系统
Phase 5: AI 辅助分析
Phase 6: 交易接口与自动化执行

## 安全要求
- 不直接执行未经验证的实盘交易。
- 交易模块必须包含风险控制。
- 所有模型输出需要可解释。
